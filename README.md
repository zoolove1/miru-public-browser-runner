# Miru Public Browser Runner

A public, secret-free Playwright runner for observing public web pages and verifying bounded public video playback.

## Public-only boundary

This repository must not contain credentials, cookies, login sessions, private prompts, personal data, unpublished content, or secret-backed workflows.

Initial canaries:

- browser startup smoke
- public HTML5 video playback
- public YouTube playback using a fixed, non-authenticated test video

Evidence is uploaded as short-lived GitHub Actions artifacts.
